# Аудит Мер по Обеспечению Безопасности Данных

## Существующие Меры

- **Доменная аутентификация**  
  Использование Active Directory для управления доступом к ресурсам.

- **Файловый сервер**  
  Хранение данных на файловом сервере.

- **1С Бухгалтерия предприятия**  
  Учет финансовых данных.

- **1С Торговля и склад**  
  Учет товарно-материальных ценностей (ТМЦ).

---

## Проблемные Зоны

- **Хранение данных в Excel и сканах**
    - Отсутствие аудита и контроля доступа.
    - Риск утечки данных.

- **Отсутствие шифрования данных**
    - Данные хранятся в открытом виде.
    - Риск несанкционированного доступа.

- **Нет ограничений на доступ к данным**
    - Все пользователи имеют доступ к данным без ролевого управления.
    - Риск несанкционированного использования данных.

- **Отсутствие мониторинга и аудита**
    - Нет системы для отслеживания доступа к данным.
    - Риск необнаруживаемых нарушений.
