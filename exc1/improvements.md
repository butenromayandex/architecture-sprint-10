## Разработка Механизма Тегирования Данных

### Список Данных для Защиты

- **Персональные данные пациентов**
    - Шифрование.
    - Обфускация.
    - Обезличивание.

- **Финансовые данные**
    - Шифрование.
    - Доступ только для сотрудников бухгалтерии.

- **Данные о сотрудниках**
    - Шифрование.
    - Доступ только для бухгалтерии и HR.

- **Данные о ТМЦ (товарно-материальных ценностях)**
    - Шифрование.
    - Доступ только для отдела склада.

- **Данные о лабораторных анализах**
    - Шифрование.
    - Доступ только для медицинских специалистов.

---

### Механизм Тегирования Данных

- **Тегирование**  
  Использование меток (tags) для категоризации данных (например, `confidential`, `personal`, `financial`).

- **Инструменты Тегирования**
    - **Apache Atlas**: Для управления метаданными и тегированием.
    - **AWS Glue Data Catalog**: Для тегирования данных в облаке.

- **Способы Тегирования**
    - Автоматическое тегирование при загрузке данных.
    - Ручное тегирование при необходимости.
