## Комментарии к Диаграмме

---

**Хранение Данных:**

**База Данных (PostgreSQL) :**
- Все конфиденциальные данные хранятся в зашифрованном виде с использованием AES-256. Регулярное резервное копирование данных с шифрованием.
- Файловый Сервер : Данные хранятся на зашифрованных разделах с использованием шифрования файловой системы (например, BitLocker).
- Контейнеры и Сервисы : Использование Docker для контейнеризации приложений. Шифрование данных в передаче между контейнерами с помощью TLS/SSL.

---

**Периоды и Условия Уничтожения Конфиденциальных Данных:**
- Персональные данные пациентов : Удаление через 7 лет после последнего контакта с пациентом. Удаление данных по запросу пациента.
- Финансовые данные : Удаление через 5 лет после завершения финансового периода. Удаление данных по запросу сотрудника бухгалтерии.
- Данные о сотрудниках : Удаление через 10 лет после увольнения сотрудника. Удаление данных по запросу сотрудника.
- Данные о ТМЦ : Удаление через 3 года после списания товара. Удаление данных по запросу сотрудника склада.
- Данные о лабораторных анализах : Удаление через 7 лет после завершения анализа. Удаление данных по запросу медицинского специалиста.

---

**Способы Защиты Данных:**
- Шифрование : Шифрование данных на уровне базы данных и файловой системы (AES-256). Использование TLS/SSL для защищенного обмена данными между системами.
- Ролевое Доступное Управление (RBAC) : Настройка ролевого доступа через Active Directory. Использование LDAP для интеграции с системами аутентификации.
- Двафакторная Аутентификация (2FA) : Внедрение двухфакторной аутентификации для доступа к системам.
- Мониторинг и Аудит : Использование ELK Stack для анализа логов и мониторинга. Настройка алертов и уведомлений для своевременного реагирования на проблемы.
- Инструменты Тегирования : Использование Apache Atlas для управления метаданными и тегированием. Автоматическое тегирование данных при загрузке.
- API Менеджмент : Использование OAuth 2.0 для аутентификации и авторизации API. Настройка API Gateway для управления доступом к API.
